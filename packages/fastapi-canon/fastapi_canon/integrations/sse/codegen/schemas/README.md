`openapi-3.2.json` is the unmodified official OpenAPI 3.2 structural schema:
https://spec.openapis.org/oas/3.2/schema/2026-08-30

Copyright The Linux Foundation, licensed under Apache-2.0.
Source: https://github.com/OAI/OpenAPI-Specification

The schema does not validate Schema Objects. The exporter additionally checks
those with Draft 2020-12 and verifies local references. No network is needed.
